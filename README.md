# ☕ Coffee Microfrontends Sandbox

Учебный проект-песочница для отработки продвинутых паттернов микрофронтенд-архитектуры на базе React, TypeScript и Vite Module Federation. Проект разрабатывается с активным использованием AI-ассистентов (Kimi). Все правила архитектуры, ограничения и контекст для агента описаны в файле AGENTS.md.

## 🎯 Цели проекта

Проект создан для практического изучения и демонстрации следующих аспектов:

- **Изоляция приложений:** независимые Zustand-сторы и SCSS-стили для каждого ремоута.
- **Кросс-коммуникация:** обмен данными между ремоутами через типизированный Event Bus без прямых импортов.
- **Race Condition:** защита от устаревших запросов при быстром переключении фильтров с помощью `AbortController`.
- **Rollback (Оптимистичные обновления):** мгновенное обновление UI с откатом состояния при ошибке сервера.
- **Архитектура FSD:** строгое соблюдение слоев (Feature-Sliced Design) внутри каждого приложения.

## 🏗 Архитектура и Стек

- **Монорепозиторий:** npm workspaces
- **Ядро:** React 18, TypeScript (strict mode)
- **Сборка:** Vite + `@originjs/vite-plugin-federation`
- **Стилизация:** SCSS Modules (с префиксами для изоляции), CSS-переменные (дизайн-токены)
- **Состояние:** Zustand (локально для каждого ремоута)
- **Тестирование:** Vitest + React Testing Library

### Структура проектов

- `apps/host-shell` (порт 3000) — приложение-хост. Отвечает за Layout (две колонки), роутинг и загрузку ремоутов.
- `apps/remote-catalog` (порт 3001) — каталог кофе. Содержит фильтры, пагинацию и карточки товаров. Реализована защита от Race Condition.
- `apps/remote-cart` (порт 3002) — корзина. Слушает события из каталога. Реализованы оптимистичные обновления с откатом при ошибках.
- `packages/shared` — общие ресурсы: типизированный Event Bus, React-хуки к нему, мок-API, дизайн-токены. Собирается в `dist` и шарится как `singleton`.

## 🚀 Быстрый старт

### Предварительные требования

- Node.js >= 18
- npm >= 9

### Установка

```bash
npm install
npm run build -w @marketplace/shared   # shared подключается к ремоутам из dist
```

### Запуск в dev-режиме

`@originjs/vite-plugin-federation` генерирует `remoteEntry.js` **только при сборке**:
в dev-режиме (`vite dev`) ремоут его не отдаёт (vite отвечает HTML-фолбэком), поэтому
хост не может подгрузить такой ремоут. Рабочий вариант локальной разработки:

```bash
# Терминал 1 — ремоуты: сборка + preview (пересобирать после изменений)
npm run serve:catalog
npm run serve:cart

# Терминал 2 — хост в dev-режиме (с HMR)
npm run dev:host
```

Открыть `http://localhost:3000`.

Если ремоут менялся — перезапустить его `serve:*` (скрипт пересобирает перед preview).
Для разработки только UI каталога/корзины без хоста можно использовать `npm run dev:catalog` /
`npm run dev:cart`, но цветовые токены объявляет только хост — standalone-страницы
ремоутов будут без палитры (это осознанное ограничение, см. AGENTS.md).

### Сборка и тесты

```bash
npm run build
npm run test
```
